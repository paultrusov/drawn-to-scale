Privacy Policy

Last updated 16 November 2026

Drawn to Scale is a small, self-hosted tool that builds short explanatory videos from public news data and publishes them to a single TikTok account owned and operated by its developer. It is not a consumer product, it has no other users, and it does not offer accounts or sign-ups.

What the app accesses

When the operator authorizes the app through TikTok Login, it requests only these permissions:

  • user.info.basic — the account's open ID, display name and avatar, used to confirm the correct account is connected before anything is uploaded.
  • video.upload — to place a finished video file into that same account's drafts for review and publication.

What is stored, and where

The app stores an OAuth access token and refresh token issued by TikTok. These are written to a single file on the operator's own computer, readable only by that user account. Nothing is stored on a hosted server, because there is no server: the app runs locally.

Alongside this the app keeps its own operational records — which videos it generated and whether an upload succeeded. These contain no personal information beyond the account the app is connected to.

What is not done

  • No data is sold, rented, or shared with third parties.
  • No advertising, tracking pixels, profiling or analytics of any kind.
  • No data is collected about anyone other than the connected account.
  • No viewer, follower, or audience data is read or retained.
  • No content is read from the account; the app only uploads.

Retention and deletion

Tokens are kept only while the integration is in use. Revoking the app in TikTok's own settings immediately ends its access. The stored token file can be deleted at any time, which has the same effect locally. There is no backup copy held anywhere else.

Third parties

The only third party the app communicates with is TikTok itself, through its official published APIs. Video content is generated from public data sources, which receive no information about the TikTok account.
